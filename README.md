# Victoria — Homewear & Pyjamas 👑

متجر إلكتروني عصري لبيجامات وملابس منزلية نسائية فاخرة. موقع ثابت (HTML/CSS/JS بدون أي بناء أو خادم)، يُستضاف **مجاناً** على GitHub Pages.

## المميزات
- تصميم فاخر (أسود · ذهبي · وردي) مستوحى من الشعار، متجاوب مع الهاتف، بالعربية (RTL).
- صفحة رئيسية، متجر مع فلترة حسب الفئة والمقاس، بحث، ترتيب.
- صفحة منتج: اختيار المقاس والكمية، تكبير الصورة، منتجات مشابهة.
- سلة تسوق جانبية + المفضلة (محفوظة في المتصفح).
- إتمام الطلب بالدفع عند الاستلام: 58 ولاية، توصيل للمنزل/للمكتب بأسعار حسب المنطقة، توصيل مجاني فوق مبلغ معيّن.
- إرسال الطلب تلقائياً إلى **واتساب** المتجر (واختيارياً إلى Formspree / Google Sheets).
- صفحة «طلباتي»، دليل المقاسات، سياسة التوصيل والاستبدال، زر واتساب عائم.

## التخصيص
| الملف | المحتوى |
|---|---|
| `assets/js/config.js` | رقم واتساب، الهاتف، البريد، روابط التواصل، العملة، أسعار التوصيل، الولايات |
| `assets/js/products.js` | الفئات والمنتجات (الاسم، السعر، المقاسات، الصورة، الوصف...) |
| `assets/img/products/` | صور المنتجات — الصور الحالية رسومات مؤقتة؛ استبدليها بصور حقيقية (`.jpg`/`.webp`، نسبة 4:5) وعدّلي حقل `image` |

> ⚠️ قبل الإطلاق: غيّري `whatsapp` في `config.js` إلى رقمك الحقيقي (صيغة دولية بدون +، مثال `213661234567`)، وراجعي الأسعار وأسعار التوصيل.

### استقبال الطلبات في Google Sheets / البريد (اختياري)
أنشئي نموذجاً مجانياً على [Formspree](https://formspree.io) وضعي الرابط في `orderEndpoint` داخل `config.js`.

## النشر المجاني على GitHub Pages
1. ادمجي هذا الفرع في `main`.
2. في المستودع: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. سيعمل ملف `.github/workflows/pages.yml` تلقائياً، ويصبح المتجر متاحاً على:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

ملاحظة: GitHub Pages المجاني يتطلب أن يكون المستودع **عاماً (Public)** في الحسابات المجانية.
يمكن أيضاً ربط نطاق خاص (مثل `victoria-dz.com`) من نفس صفحة الإعدادات.
